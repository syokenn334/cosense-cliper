# Cosense Clip（非公式）

閲覧中のWebページやYouTube動画、Xの個別投稿へのリンクを、自分が参加しているCosense（旧Scrapbox）のプロジェクトに保存するChrome拡張です。タイトル・コメント・タグを確認して保存すると、新規ページを作成します。

### 連携方法と未確認事項

Cosenseへの書き込みには、利用者本人のPersonal Access Token（PAT）と、`/api/pages/v2/{project}/page-edit-for-ai/preview`・`submit` を使います。同じエンドポイントは[公式CLIの実装](https://github.com/helpfeel/cosense-cli/blob/main/src/commands/previewEdit.ts)にもありますが、[公式ヘルプ](https://scrapbox.io/help-jp/Cosense_Skill_%26_CLI)はAgent Skillを介した利用を案内しています。本拡張はSkillを介さず直接APIを呼び出しており、この使い方が公式にサポート・許諾されているかは未確認です。

YouTubeとXでは、表示中のページのHTMLからタイトル・投稿URL・画像URLなどを読み取ります。各サービスの規約には自動アクセスやスクレイピングに関する制限があり、本拡張の処理が許容されるかは未確認です。仕様・規約の変更等により、機能を変更または停止する場合があります。

参照先： [Cosense利用規約](https://cosen.se/terms?lang=ja) · [YouTube利用規約](https://www.youtube.com/static?template=terms) · [X利用規約](https://x.com/tos?lang=ja)

## インストール

Chrome 120以降を対象とする、開発者モードでの手動導入です。Chrome Web Storeの審査を受けた配布物ではありません。内容を確認し、信頼できるコードとして導入する場合に使用してください。

1. [リポジトリ](https://github.com/syokenn334/cosense-cliper)の「Code」→「Download ZIP」で取得し、ZIPを展開します。Gitを使う場合は `git clone git@github.com:syokenn334/cosense-cliper.git` でも取得できます。
2. Chromeで `chrome://extensions` を開き、「デベロッパーモード」を有効にします。
3. 「パッケージ化されていない拡張機能を読み込む」から **`extension` フォルダー** を選びます。`manifest.json` が直接入っているフォルダーで、リポジトリのルートではありません。
4. 拡張の「詳細」→「拡張機能のオプション」を開きます。
5. 保存先プロジェクト名（例：`my-notes`）と、**自分で発行したPAT**を入力し、「接続を確認して保存」を押します。他人とPATを共有しないでください。
6. 既に開いているYouTube・Xのタブを再読み込みします。

利用時のビルド作業やNode.jsのインストールは不要です。PATの発行については[公式ヘルプ](https://scrapbox.io/help-jp/Personal_Access_Token)を参照してください。

保存先が `https://scrapbox.io/my-notes/` なら、プロジェクト名には `my-notes` だけを入力します。Chrome右上の拡張機能メニュー（パズルのアイコン）からCosense Clipを固定すると、一般Webページでも呼び出しやすくなります。読み込んだ `extension` フォルダーは削除・移動せず保管してください。

更新は手動です。同じ場所のファイルを新しい版に差し替え、`chrome://extensions` で拡張を再読み込みした後、対象サイトのタブも再読み込みしてください。

## 使い方

| 対象 | クリップの開き方 |
| --- | --- |
| 一般Webページ | Chromeの拡張アイコンを押す |
| YouTube | 動画の操作欄の紙クリップ、または「その他の操作」内の「＋ Cosenseにクリップ」を押す |
| X／Twitter | 投稿の操作欄の紙クリップ、または「…」メニュー内の「＋ Cosenseにクリップ」を押す |

サイト上のボタンが表示されない場合は、動画・投稿の詳細ページを開き、Chromeの拡張アイコンを試してください。

1. 保存先・タイトル・コメント・タグを確認します。Xのタイトルは空欄で開くので入力してください。
2. 「保存する」を押します。タグはスペース・カンマ区切り、コメントはCosense記法として保存します。
3. 保存完了後にリンクが表示されます。保存処理だけではCosenseのタブを開きません。

例えばタイトルを「あとで読む記事」、コメントを「週末に確認する」、タグを「技術 あとで読む」として保存すると、次の内容の新規ページになります。

```text
あとで読む記事
https://example.com/article

週末に確認する

#技術 #あとで読む
```

Xは個別投稿だけが対象です。検索・ホーム・プロフィールのページ自体は保存できませんが、その画面に表示された個別投稿は対象にできます。

### 保存内容

順序は **タイトル → URL → コメント → 取得できた画像URL → タグ** です。空の項目は省略し、タイトルはページのタイトル行にだけ入れます。

- 一般WebはURLを保存します。記事本文を自動で転載する機能はありません。
- YouTube・XのURLは `[https://…]` の形式で保存します。Cosense側で埋め込み表示される場合があります。
- Xでは投稿から取得できた最初の画像、または動画サムネイルのURLを最大1件追加します。画像ファイルをCosenseへアップロードする処理はありません。
- スレッド全体、動画本体、動画字幕を取得する機能はありません。

クリップごとに新規ページを作ります。保存前の確認で同名タイトルを検出した場合はエラーにし、既存ページへ自動追記・上書きはしません。タグに空白を含める入力には未対応です。

## データと認証情報の扱い

### 読み取り・送信

一般Webでは拡張アイコンの操作時にページ情報を読み取ります。YouTube・Xではボタンを追加するためにスクリプトが自動で動作し、表示中の動画・投稿の情報をブラウザー内で読み取ります。保存ボタンを押すと、選択した情報と入力内容をCosenseへ送信します。

接続確認時にはPATを使ってCosenseのユーザー情報と保存先へのアクセスを確認します。保存時には書き込みと本文の再取得を行います。通信先は `https://scrapbox.io` で、PATは認証ヘッダーとして送ります。PAT所有者として操作するため、ブラウザーでログインしているアカウントとは異なる場合があります。

本拡張には、開発者のサーバーへの送信、アクセス解析、広告用トラッキングを行う処理はありません。保存先の閲覧権限はCosenseのプロジェクト設定に従います。保存したページの画像・埋め込みを表示する際には、Cosenseやブラウザーから元サービスへの通信が発生する場合があります。

### 端末内の保存

- PATは標準ではChromeのセッションストレージで保持します。
- 「このブラウザにPATを保存する」をオンにすると、拡張のローカルストレージに永続保存します。**拡張側で暗号化しておらず、暗号化保管庫ではありません。**
- 保存先・既定のタグ・PAT所有者の名前・保存履歴をローカルに保持します。履歴にはタイトル、元URL、保存先URL、処理状態などが含まれます。
- Chrome同期には保存しません。ページに挿入するスクリプトから拡張ストレージへ直接アクセスすることは禁止し、PATをページ内UIへ渡しません。

設定画面で接続を解除すると、接続設定と拡張内のPATを削除します。保存履歴やCosenseに作成済みのページは削除しません。PAT自体を失効させる場合はCosense側で取り消してください。拡張の端末内データをまとめて削除する場合は拡張をアンインストールし、Cosense上のページは別途管理してください。

PAT、設定画面の認証情報、非公開ページの内容を、リポジトリやIssue・スクリーンショットへ掲載しないでください。

### 必要な権限

| 権限・対象 | 用途 |
| --- | --- |
| `activeTab`・`scripting` | 操作したタブにクリップ画面を表示する |
| `storage` | 接続設定・PAT・保存履歴を保持する |
| `https://scrapbox.io/*` | 接続確認、ページの作成、保存結果の確認 |
| YouTube・X／Twitterの対象ページ | クリップボタンの追加、ページ情報の読み取り、入力中のショートカット干渉防止 |

## 保存に失敗したとき

設定画面の「最近の保存」で結果を確認できます。送信後に通信が切れた場合は「要確認」とし、自動再送を止めます。保存先を確認し、「確認済みにする」を押すとそのURLを再度クリップできます。「確認済み」は保存成功の判定やページの削除ではありません。

入力途中で閉じた画面の下書きは保持しません。送信後は画面を閉じてもバックグラウンドで処理します。

## デザイン

入力画面はOSのライト／ダーク設定に追従し、右上に表示します。背景のぼかし・暗転は行いません。外部フォントはダウンロードせず、端末のフォントを使用します。ダーク配色は [nagurigaki-exe/settings](https://scrapbox.io/nagurigaki-exe/settings) を参考にしています。

## 制限・検証範囲

- Chromeの内部ページやChrome Web Storeなど、拡張の注入が許可されないページでは利用できません。
- サイトのHTML構造、表示言語、テーマ、ログイン状態、APIの変更によって動作しなくなる場合があります。Xの引用投稿と添付画像の判定も完全ではありません。
- Chromium上で設定・クリップ・保存結果・エラー処理・PATの隔離を自動テストしています。Cosense APIの応答にはモックを使用します。
- 実際のYouTube動画詳細画面で、ボタン・メニュー・情報取得・入力中のショートカット干渉防止を確認しています（2026-09-24）。
- 開発時のPoCでは実プロジェクトへのPATによる作成・本文再取得を確認していますが、全環境での動作を保証するものではありません。Xのログイン後の実画面、YouTubeの全一覧形式・Shortsは未検証です。

## 開発・テスト

```powershell
npm install
npx playwright install chromium
npm run check
npm test
```

既存のChromiumを使う場合は `PLAYWRIGHT_CHROMIUM_EXECUTABLE` に実行ファイルのパスを指定できます。ブラウザーテストは `.browser-test/` に専用のプロファイルとスクリーンショットを作成し、通常使用中のChromeプロファイルには触れません。テスト用の追加ホスト権限は一時コピーにだけ付与します。

`node scripts/check-youtube.mjs` は実際のYouTubeにアクセスする追加チェックです。Cosenseへの保存は実行しません。

配布用ファイルは `extension/` 内です。`node_modules/`、`.browser-test/`、`.env`、端末固有の設定や認証情報を含めないでください。
